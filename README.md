 Fart Superman Game
一款趣味休闲网页小游戏，纯前端单文件实现，无需后端，浏览器直接打开游玩。

 🎮 游戏玩法
1. 输入任意人名
2. 选择对象：【喜欢的人】/【讨厌的人】
- 讨厌的人：释放烟雾屁特效趣味互动
- 喜欢的人：释放爱心、花瓣、气泡浪漫特效
3. 支持随时重置，重新开启游戏

 🚀 游玩方式
### 在线访问
> 部署完成 https://fart-superman-game.vercel.app

### 本地游玩
1. 下载仓库内 `index.html`
2. 使用浏览器双击打开

> ⚠️ 提示：微信/QQ内置浏览器容易动画异常，推荐 Chrome、Edge、手机系统浏览器打开

## 🛠️ 技术栈
HTML5 + CSS3 + Vanilla JavaScript
零外部依赖，全部功能内置在单个HTML文件。
